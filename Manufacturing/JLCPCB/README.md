# JLCPCB bare-PCB upload package

`diy-eeg-pcb-fabrication.zip` is the fabrication-only upload archive for a bare PCB order. Upload this ZIP to JLCPCB's PCB quote page.

It contains the standard RS-274X Gerber layers for the four-layer board plus the plated and non-plated NC drill files. It deliberately excludes Gerber X2, BOMs, CPL/pick-and-place data, PDFs, STL files, source CAD files, reports, and design history.

Before placing an order, inspect JLCPCB's rendered preview and confirm the board outline, four copper layers, and drill holes. This ZIP is not an SMT assembly package; assembly additionally requires a JLC-formatted BOM and CPL file.
