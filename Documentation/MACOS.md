# Using the documentation on macOS

- [Root README](../README.md) for the overall route
- [`Software/Firmware_Platformio_Project/MACOS.md`](../Software/Firmware_Platformio_Project/MACOS.md) for firmware flashing on a Mac
- [`src/diy_eeg_mac`](../src/diy_eeg_mac) for the Mac BLE receiver and experiment tools

Use the Python package in this repository on macOS.

Altium Designer runs on Windows only. To order or check the board on a Mac, use the exported files in [`Manufacturing/JLCPCB`](../Manufacturing/JLCPCB) and view the Gerbers with JLCPCB's viewer, `gerbv`, or KiCad GerbView. See [Hardware](../Hardware/README.md).
